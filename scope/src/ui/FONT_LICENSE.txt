"Scope 8x8" bitmap font
=======================

The 8x8 monospace bitmap font embedded in scope/src/ui/font.rs (the GLYPHS array)
was authored by hand for the streamcraft-scope crate. It is an original work — no
third-party font data was copied — and is dedicated to the public domain.
